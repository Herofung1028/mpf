ℹ️ 大市基準對應規則與指標定義
  • 港股 / 中國 → 恒生指數基金；北美 / 美股 → 北美股票追蹤基金；歐洲 → 歐洲股票追蹤基金；亞太 → 亞太股票追蹤基金。
  • 日本 / 韓國 / 台灣、康健護理 → 全港同類基金平均（同業平均）。
  • 環球股票 / 混合資產 → 同計劃「核心累積基金」（DIS）；債券 / 保證 → 同計劃「強積金保守基金」。
  • 優先使用同計劃內的基準基金；若無，則回退至恒生 ValueChoice 或其他計劃的同類追蹤基金。
  • Alpha ＝ 基金回報 − 基準回報，兩者以相同的結束日期計算（避免每日與每月數據錯開）。≥ +1.5% 強於大市；≤ −1.5% 弱於大市。
  • 年化波幅：以近 3 年月末價格計算對數回報標準差，年化係數按實際平均數據間距動態調整（月度 ≈ √12）。風險回報比 ＝ 同期年化回報 ÷ 年化波幅；✓ 代表高於同計劃 DIS 核心累積基金。
